## Como Capturar

### No Emulador/Simulador
- **Android**: Botão de câmera na toolbar do emulador
- **iOS**: `Cmd+S` no simulador

### No Dispositivo Físico (Expo Go)
- **Android**: Power + Volume Down
- **iOS**: Side Button + Volume Up

### No Navegador (Web)
- **Mac**: `Cmd+Shift+4` → selecione área
- **Windows**: `Win+Shift+S` → selecione área
- **Chrome DevTools**: `Cmd+Shift+P` → "Capture screenshot"

## Dicas de Qualidade

1. **Use dados realistas** - Não dados de teste óbvios
2. **Oculte dados sensíveis** - Emails, nomes reais se necessário
3. **Mostre estados variados** - Lista vazia, com dados, carregando
4. **Formato PNG** - Melhor para UI com texto nítido
5. **Consistência** - Mesmo device frame em todas
